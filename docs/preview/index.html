Образцы новых разделов

Статические HTML-макеты для согласования перед внедрением. Откройте любой файл в браузере — интерфейс повторяет дизайн-систему сайта (Tailwind, палитра brand/emerald, карточки rounded-2xl, тень soft).

P0 · Новый раздел

/diff — Сравнение редакций + Протокол разногласий

Загрузка двух редакций, подсветка правок, таблица «Редакция Исполнителя / Заказчика / Согласованная» (ст. 445 ГК), экспорт в DOCX/PDF.

P1 · Новая страница

/verify/[hash] — Проверка подлинности документа

Публичная страница по QR из колонтитула документа. Показаны состояния: подтверждён / не найден / изменён.

P2 · Новый раздел

/mchd — Визуализатор машиночитаемых доверенностей

Загрузка XML (формат 003) → человекочитаемый бланк: доверитель, представитель, коды полномочий, срок действия.

P0 · Компонент в конструкторе

Проверка статуса самозанятого (НПД) по API ФНС

Поле ИНН исполнителя: все состояния — не проверено, проверка, подтверждён, не самозанятый, сервис недоступен.

P1 · Компонент сканера

MRZ-сканирование паспорта камерой

Режим внутри «Сканера документов»: камера + рамка зоны MRZ, непрерывное распознавание в браузере (ONNX ~300 КБ).

Примечание: эти файлы — только макеты. Реальные данные и парсинг (.docx, XML МЧД, MRZ) подключаются на этапе внедрения; сетевые запросы (ФНС) идут через серверный прокси.
