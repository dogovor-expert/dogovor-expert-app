# 0002. Платёжный шлюз: YooKassa

## Status

Accepted (2024-Q3, обновлено 2026-09-05)

## Context

Нужен платёжный шлюз для PRO-подписки (990 ₽/мес, 8490 ₽/год):
- Поддержка карт МИР, Visa, Mastercard
- НДС (юр. лица, ИП)
- Чеки по 54-ФЗ
- Рекуррентные платежи
- Возвраты (для отмены подписки)

## Decision

Используем **YooKassa** (бывшая Яндекс.Касса) — единственный полностью легальный шлюз для РФ.

### Причины
1. **Соответствие 54-ФЗ** — автоматические чеки в ОФД
2. **Поддержка МИР** — обязательно для RU-аудитории
3. **СБП (Система Быстрых Платежей)** — комиссия 0.4% vs 2.5% у карт
4. **Рекуррентные платежи** — для подписки без повторного ввода карты
5. **API + Webhooks** — интеграция через /api/subscription-status и /api/yookassa/webhook
6. **Без зарубежных требований** — KYC, валютный контроль

## Consequences

### Положительные
- Юридически чистая работа в РФ
- Один API для всех способов оплаты
- Встроенная защита от chargeback'ов
- Личный кабинет для отслеживания транзакций

### Отрицательные
- **Только РФ** — для EU/US нужен Stripe (отдельный аккаунт)
- **Комиссия 3.5%** на карты (СБП 0.4%)
- **KYC обязателен** — нужны документы ООО/ИП
- **Задержка вывода** — 1-3 рабочих дня

## Alternatives Considered

### Stripe
- ❌ Санкции в РФ (частичные)
- ❌ Нужен иностранный банк
- ✅ Лучше для международных платежей

### Robokassa
- ❌ Устаревший API
- ❌ Хуже UX для рекуррентных платежей
- ✅ Дешевле (2.5%)

### Tinkoff Payments / Sberbank
- ❌ Нет СБП
- ❌ Сложнее интеграция
- ✅ Для крупных B2B

## Implementation

- API: <https://yookassa.ru/developers/api>
- Webhook: <https://yookassa.ru/developers/using-api/webhooks>
- Webhook URL: `/api/yookassa/webhook` (НЕ `/api/subscription-status`!)
- Тестовые ключи: shop_id = `test_shop`, secret = `test_...`
- Production: shop_id в env, secret в env
