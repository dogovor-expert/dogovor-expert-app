# Dogovor.expert

**Онлайн-сервис юридических документов**: конструктор договоров, расписок, заявлений и доверенностей с экспортом в PDF/DOCX, квалифицированной электронной подписью (УКЭП), OCR и 20+ правовыми калькуляторами.

🌐 **Живой сайт:** [https://dogovor.expert](https://dogovor.expert)

## Что умеет сервис

### 📄 Конструктор документов
Пошаговое заполнение полей, автозаполнение из DaData, предпросмотр в реальном времени, юридическая проверка (аудит полей), экспорт в PDF и DOCX, автосохранение черновиков с разрешением конфликтов, синхронизация между устройствами.

### 📚 Библиотека шаблонов
Сотни форм: договоры купли-продажи, аренды, оказания услуг, акты, заявления, жалобы, иски, кадровые документы, налоговые формы, миграционные документы — с SEO-страницами и онлайн-заполнением.

### ✍️ Юридически значимая подпись
Подписание документов УКЭП через КриптоПро прямо в браузере: PAdES-встраивание, проверка цепочек доверия по TSL Минцифры, CRL/OCSP-ревокция, метки времени TSA.

### 🔢 Правовые калькуляторы
Госпошлины (ст. 333.19 НК РФ), пени по ст. 395 ГК, отпускные по ПП РФ №540 с премиями, алименты с прожиточным минимумом по 89 регионам, таможенные платежи по живому курсу ЦБ, ОСАГО/КАСКО с КБМ, налоги УСН/НПД/НДФЛ, штрафы ГИБДД, производственный календарь с переносами постановлений Правительства.

### 📷 OCR и конвертеры
Распознавание текста с фото/сканов, конвертация DOCX ↔ PDF, объединение/разделение PDF, изображения → PDF.

### 💳 Подписка и биллинг
Оплата через ЮKassa, автопродление, промокоды, история платежей, role-based админ-панель с аудит-логом.

## Технологии и инженерное качество

| Область | Решение |
|--------|---------|
| Фреймворк | Next.js 15 (App Router, RSC), React 19, TypeScript strict |
| Данные | Supabase (Postgres, RLS, аутентификация, storage) |
| UI | Tailwind CSS, container queries, a11y по ARIA APG |
| Документы | pdf-lib, mammoth, pdfjs, PAdES/CMS (pkijs) |
| Тесты | 468 unit-тестов (Vitest), e2e (Playwright), security-invariants |
| Безопасность | CSP с nonce, CSRF-гейты, Zod на всех API-границах, rate-limit (Upstash), magic-bytes валидация загрузок, gitleaks в pre-commit |

Сервис обслуживает реальных пользователей: оплата, документы с юридической силой, персональные данные — под 152-ФЗ (password-protected шеринг, аудит-логи, шифрование нулевого разглашения для приватных данных).
