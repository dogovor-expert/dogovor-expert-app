# PDF Export Verify

НЕЛЬЗЯ писать «исправлено» для PDF-бага, пока не пройдены ВСЕ пункты ниже.
Проверка программная (координаты и порядок), не «на глаз».

## Чек-лист

1. **Собери PDF с реальными тестовыми данными** (не пустой шаблон):
   - минимум 2 разных документа (например `dkp-auto` и `act-transfer-auto`);
   - обязательно документ с блоком «ЛИСТ ПОДПИСАНИЯ И ПРОТОКОЛ ПЭП»;
   - заполни поля формы реальными значениями (id полей, не name).

2. **Скачай PDF ИМЕННО с прода** (не localhost, не тестовый билд):
   - `npm run test:prod` — скачивает реальные PDF с dogovor.expert в `%LOCALAPPDATA%\Temp\opencode\prod-*.pdf`;
   - если деплой ещё не выкачен — сначала деплой, потом проверка.

3. **Прогони программный анализ** (`C:\Users\alikpc\AppData\Local\Temp\opencode\pdf-vision.py`):
   - `python pdf-vision.py <file.pdf>`;
   - проверь ПОРЯДОК y-координат блоков: шапка/заголовок сверху (y ~ 57-90), затем разделы по логическому порядку (y возрастает), колонтитул и watermark внизу (y ~ 800-822);
   - проверь watermark-текст: «Сформировано бесплатно на сервисе Dogovor» без хвоста «— PRO-версия без пометки»;
   - проверь отсутствие пустой области сверху (первый span на y < 100).

4. **Проверь бандл с прода** (когда правишь логику рендера):
   - скачай `/_next/static/chunks/2172-*.js` с dogovor.expert;
   - маркер инверсии вертикали: `this.y=o.h-i.top` (ПРИСУТСТВУЕТ) вместо `this.y=i.top` (СТАРЫЙ КОД);
   - хэш чанка должен совпадать с локальным `.next/static/chunks/2172-*.js`.

5. **Проверь pixel-профиль** (для страниц, где был вертикальный баг):
   - `python -c` скрипт из истории: тёмные пиксели по полосам 200px;
   - текст начинается сразу сверху, нет пустой полосы в верхней трети.

Только после прохождения пунктов 1-5 можно писать «исправлено».

## Контекст

- Единственный рендерер PDF: `src/lib/exportPdf.ts` (buildPdf) — текст, лист подписания (buildSignHtml из builder/page.tsx), колонтитулы, watermark.
- Баг «текст снизу вверх»: старый код рисовал от низа (шапка y=762 из 842). Фикс: `this.y = A4.h - margin.top`.
- Деплой: батч из `%LOCALAPPDATA%\Temp\opencode\proj` (синхронизировать robocopy /MIR + свежий `.next`!), затем finalize + poll, затем проверка бандла с прода. «READY+PROMOTED» НЕ является доказательством доставки.
