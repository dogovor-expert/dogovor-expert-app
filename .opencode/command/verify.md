---
description: Запуск верификации кода проекта Dogovor (TypeScript + Vitest)
---

Проведи быструю верификацию проекта:
1. Выполни `npx tsc --noEmit` для проверки типов.
2. Выполни `npm run test:unit` для проверки всех unit-тестов.
3. Проверь вывод и скомпонуй лаконичный отчет о результатах (без вывода всех прошдших тестов, только статус и ошибки при их наличии).
4. Если verify зелёный и менялся код (не только доки) — напомни: перед коммитом прогони `/ocr-delegate` для AI-ревью изменений.
