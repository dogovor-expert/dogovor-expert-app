# Полный промт: Сайт системы юридических документов "Dogovor"

## 1. Концепция

Создать полнофункциональный веб-сайт на Next.js 14 (App Router) + React 18 + TypeScript + Tailwind CSS — система для создания и управления юридическими документами (ДКП, ОСАГО, доверенности и т.д.), проверки автомобилей по VIN, расчёта страховки и администрирования.

## 2. Общий дизайн

- **Цветовая схема**: светлая тема (bg-gray-50), белые карточки (bg-white, border-gray-100, rounded-xl), акцентный синий (brand-500: #2563eb, brand-50 для подложек)
- **Шрифты**: Inter (системный sans-serif)
- **Тени**: shadow-soft (0 1px 3px rgba(0,0,0,0.05)), shadow-elevated (0 10px 25px rgba(0,0,0,0.08))
- **Анимации**: hover:-translate-y-0.5, transition-all duration-200, fade-in

## 3. Глобальная структура

```
┌─────────────────────────────────────────────┐
│ Хедер (поиск, уведомления, профиль)          │
├──────────┬──────────────────────────────────┤
│ Сайдбар  │  Основной контент (children)      │
│ (264px)  │  p-6, max-w-7xl mx-auto           │
│          │                                    │
│ - Главная│                                    │
│ - Констр.│                                    │
│ - ...    │                                    │
└──────────┴──────────────────────────────────┘
```

- **Хедер**: высота h-16, bg-white, border-bottom. Слева: бургер-меню (на мобильных), поисковая строка (w-80, bg-gray-50, rounded-xl). Справа: иконка колокольчика с красной точкой, аватар пользователя.
- **Сайдбар**: w-64, bg-white, border-right. Разделы: Основные (Главная, Конструктор ДКП, Автотека, ОСАГО, ИНН/НДС, B2B, Админка), Документы (Документы, Редактор, Шаблоны, Просмотр, Корзина), Бизнес (Аналитика, Команда, Тарифы, Интеграции, Активность). Внизу: Настройки, Помощь, плашка "152-ФЗ".
- **Активный пункт**: bg-brand-50 text-brand-700.
- **Адаптивность**: на lg: сайдбар всегда виден, на <lg: оверлей + бургер.

## 4. Страницы

### 4.1 Главная (/) — Workspace
- Приветствие: "Добро пожаловать в Dogovor"
- 4 быстрых действия (Создать ДКП, Проверить VIN, Рассчитать ОСАГО, Шаблоны) — карточки с иконками, ссылки
- 4 статистики (Всего документов, Проверок VIN, Расчётов ОСАГО, Пользователей) — числа с изменениями
- Список последних 5 документов с типом, статусом, датой (ссылка на /documents)
- Боковая панель: ссылки на инструменты, карточка "Премиум" с прогресс-баром

### 4.2 Конструктор ДКП (/constructor)
- Выбор шаблона документа (ДКП, Акт приёма-передачи, Расписка, Заявление ГИБДД) — сетка кнопок с поиском
- Окно загрузки фото (OCR) — drag-and-drop область, имитация распознавания (заполняет поля формы)
- Форма с табами: Продавец / Покупатель / ТС / Условия — поля ввода: ФИО, паспортные данные, адреса, VIN, цена
- Кнопка "Правовой аудит" — проверка VIN на длину, заполненность полей, рекомендации. Выводит score и предупреждения.
- Панель предпросмотра документа — HTML-шаблон с подставленными значениями, кнопки печати, копирования JSON
- Блок "Связанные документы" — ссылки на сопутствующие шаблоны с переносом данных
- Футер: "Соответствует 152-ФЗ"

### 4.3 Автотека (/autoteka)
- Поле ввода VIN (17 символов, uppercase, font-mono)
- Кнопка "Проверить" — имитация проверки (1.8 сек задержка)
- Результат: марка/модель, год, статус учёта, розыск, ДТП, залоги — цветные индикаторы
- Кнопка "Перенести данные в конструктор ДКП" — dispatch CustomEvent для автозаполнения

### 4.4 ОСАГО & КБМ (/osago)
- Пошаговый мастер (3 шага с табами):
  1. Город, мощность (л.с.), количество водителей, срок
  2. Возраст, стаж водителя
  3. Результат: стоимость полиса, название страховой компании, КБМ, класс
- Кнопки "Назад"/"Рассчитать" с лоадером
- Метка: "Расчёт по методике ЕАИСТО РСА"

### 4.5 ИНН и НДС (/utils)
- Две колонки:
  - Валидатор ИНН: поле ввода 10/12 цифр, кнопка "Проверить", результат (корректен/некорректен, тип лица)
  - Калькулятор НДС: сумма с НДС, ставка (20/10/0%), результат (НДС, сумма без НДС)

### 4.6 B2B Кабинет (/b2b)
- Три карточки статистики: Баланс, Сотрудники, Документы/месяц
- API-ключ: текстовое поле readonly, кнопки "Копировать", "Обновить"
- Список сотрудников: аватар (первая буква), имя, роль, email, статус (Активен/Неактивен)

### 4.7 Админ-панель (/admin)
- 4 карточки статистики: Документы, Пользователи, Проверки VIN, Расчёты ОСАГО
- Блок "Система": статусы API, БД, CPU, RAM (цветные индикаторы)
- Лог активности (7+ записей): точка с цветом (create=зелёный, delete=красный, и т.д.), действие, пользователь, время

### 4.8 Dashboard (/dashboard)
- "Доброе утро, Иван!" + кнопка "Новый документ"
- 4 карточки статистики: Всего документов, Активных, На подписи, За неделю
- Список последних 5 документов + правый блок (быстрые действия, Премиум)

### 4.9 Документы (/documents)
- Заголовок + кнопка "Создать"
- Поиск + фильтры по типу (Все, ДКП, ГИБДД, Доверенность, Акт) и статусу (Все, Готово, Черновик, На подписи, Архив)
- Таблица с checkbox, названием, типом, статусом (цветные badge с точкой), автором, датой, размером, действиями (просмотр, скачивание, удаление)
- Пагинация

### 4.10 Редактор (/editor)
- Заголовок документа, статус "Черновик", кол-во символов
- Панель инструментов: Undo/Redo, Bold/Italic/Underline, Align, List, Type, Image
- Текстовое поле (textarea, font-mono, min-h-[600px]) с предзаполненным текстом ДКП
- Кнопки "Предпросмотр" и "Сохранить" (с имитацией сохранения)

### 4.11 Шаблоны (/templates)
- Поиск + категории (Все, ДКП, ГИБДД, Доверенности, Акты)
- Переключатель вида: сетка / список
- Карточки/строки с градиентной полосой сверху, иконкой, названием, описанием, кол-вом использований, категорией, кнопкой "Использовать" (по ховеру)
- Фильтрация по категории и поиску

### 4.12 Тарифы (/pricing)
- Переключатель "Месяц / Год"
- 3 карточки: Базовый (0₽), Премиум (4 900₽/49 000₽), Корпоративный (19 900₽/199 000₽)
- Выделенная карточка "Премиум" (border-brand-500, bg-brand-50)
- Список возможностей для каждого плана
- Кнопки "Подключить" / "Текущий план"

### 4.13 Аналитика (/analytics)
- 4 карточки суммарной статистики
- Таблица "Документы по месяцам" (гистограмма из div с height)
- Топ пользователей
- Распределение по типам документов (круговые индикаторы)

### 4.14 Команда (/team)
- Карточки участников (6-8): аватар (градиент), имя, роль, email, тоггл статуса (Активен/Неактивен)
- Кнопка "Пригласить участника"
- Фильтрация по ролям

### 4.15 Просмотр (/preview)
- Режим чтения документа в сепия-стиле (bg-sepia-100)
- Регулировка зума (50%-200%)
- Переключение страниц
- Панель комментариев сбоку (3 комментария, поле ввода)

### 4.16 Интеграции (/integrations)
- Поиск + категории (Хранилище, Подпись, Бухгалтерия, Почта, Мессенджеры, Платежи, Данные)
- 14 интеграций (Google Диск, DocuSign, 1С, Telegram, ЮKassa и др.)
- Карточки: иконка, название, описание, статус (Подключено/Нет), кнопка "Подключить/Отключить" — toggle в реальном времени
- Счётчик "X из 14 активны"

### 4.17 Активность (/activity)
- Фильтр по типу действия (Всё, Создание, Удаление, Экспорт, Проверка)
- Лента 15+ событий с иконками типизованными, временем, пользователем
- Timeline-стиль

### 4.18 Настройки (/settings)
- Профиль: имя, email, телефон, компания (поля ввода)
- Уведомления: 3 чекбокса (Email, SMS, Telegram)
- Параметры: язык, тема, подпись
- Кнопка "Сохранить" с обратной связью

### 4.19-4.25 Остальные страницы (Корзина, Безопасность, Биллинг, Помощь и т.д.)
- Каждая с реальным контентом, интерактивностью, соответствующим описанию

## 5. Компоненты UI (src/components/ui/)

- **Card**: variant (default/elevated/glass/flat/sharp), padding (none/sm/md/lg)
- **Button**: variant (primary/secondary/ghost/danger/outline), size (sm/md/lg)
- **Badge**: variant (blue/green/amber/red/purple/gray/teal/pink), size (sm/md), dot-опция
- **Table**: variant (default/striped/bordered/minimal), TableHead, TableBody, TableRow, TableHeader, TableCell

## 6. Технические требования

- Next.js 14 App Router с "use client" для интерактивных страниц
- Tailwind CSS для стилизации (кастомные цвета brand-*, shadow-soft, shadow-elevated в globals.css)
- lucide-react для иконок
- Все данные статические (зашиты в компоненты), никаких API-запросов
- Все кнопки и элементы управления рабочие (toggle, filter, search, modal, animation)
- Единый сайдбар на всех страницах через root layout
- Адаптивность: десктоп (сайдбар + контент), мобильные (оверлейное меню + бургер)
- Шрифты: Google Fonts (Inter, Playfair Display, JetBrains Mono)
